# Security reports

Do not include live API keys, private resumes, transcripts or recordings in public issues. Use a synthetic reproduction.

For sensitive reports, use GitHub private vulnerability reporting if it is enabled for this repository. Otherwise open a minimal issue requesting a private reporting channel without publishing exploit details or sensitive data.

This is an experimental source release, not an audited or production-hardened application. Dependency updates, permission handling and persistent local data need continued review. See PRIVACY_POLICY.md for the interview workflow's current data handling.
