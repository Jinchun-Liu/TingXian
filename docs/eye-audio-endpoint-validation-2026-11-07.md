# AV-E2a 音频端点适配器：源码、合成与只读检查

日期：2026-11-07。分支 `feat/windows-eye-output-20261107`，起点
`0b00846002e4d5947196432d462150c92d04f8b6`。本轮没有应用安装包、第三方驱动安装、
新虚拟设备、摄像头/麦克风采集、播放、模型推理或资料外发。教育和归档分支保持原位。

## 决策与实现

假设：明确端点 ID、共同适配器归属、消费时钟和有限写入能形成可单独验收的 Windows
原声输出边界。决策价值：为之后获准的合成端点测试准备真实 WASAPI 实现，而不把
内存时间线当作虚拟麦克风。停止条件：错选物理扬声器、错误来源/代次、无界缓冲、
普通回归启动媒体或忽略清理失败；出现则先修复，不推进实际输出。

新增 [audio/windows](../audio/windows/README.md)：元数据枚举、DeviceTopology 到 PnP
归属、指定虚拟线缆配对、原生格式协商/事件/缓冲/时钟/写入/停止，以及可注入内存后端。
只接受已核对 INF 的基础 VB-CABLE 硬件/服务标识；没有默认设备回退。原生准备阶段重新
枚举，不能依靠调用方提供的伪造设备清单打开扬声器。PnP 匹配不是驱动签名或许可证明。

48 kHz float32，明确单/双声道，20–100 ms 实际缓冲上限，单次最多 20 ms，只有一张
待写票据。原声单声道复制到双声道不改音量、不生成语音；错源/非法样本拒绝。读设备
消费位置与 QPC，按频率换算；过期/欠载/倒退/失效撤销 lease 再清理。真实两路 owner、
Rust 桥接和事件循环尚未接入，不能声称已实现完整音画同步。

停止分别记录 Stop、Reset 和外部排空状态。微软 Reset 的保证仅限当前客户端；Windows
后端固定报告外部排空未验证，并拒绝复用。未来所有者须跨对象/进程保留该门槛，不能
通过重新 new 一个对象绕过。调度检查和实际 ReleaseBuffer 之间仍可能被系统抢占，
真实写入时延、线缆/接收端残留与持续漂移待实测，2 ms 写入余量不作为性能保证。

## 本机实际结果

Windows 11 Pro 10.0.26200，Ryzen 7 9700X，RTX 4070 Ti SUPER 驱动 32.0.16.1088；
本轮不使用 GPU。D 盘检查时剩余约 96 GiB。MSVC 19.29 / VS 2019 Build Tools、
Windows SDK 10.0.19041.0、CMake 4.4.5，Release，`/W4 /WX`。

| 检查 | 预期与实际 | 证据边界 |
| --- | --- | --- |
| 编译原生库、测试和 probe | 成功，无编译警告 | 原生方法可编译，不证明真实流可运行 |
| 内存回归 | 12 组全部通过 | 包括多分支输入/格式/故障注入，不按断言数扩增为测试数 |
| PCM 与消费时钟 | 实际样本逐点核对，时钟单位故意设为帧数的 4 倍 | 无音频播放，不是设备消费实测 |
| 错源/迟到/背压/设备错误 | 拒绝写入、撤销 lease、保留错误 | 合成后端；两路设备尚未接通 |
| 停止/重启 | 清理失败与外部排空未知阻止重启；内存清空后 3 次重启无旧 PCM | 只验证内存后端可证明的排空 |

| CTest | 3/3 通过（内存、枚举、无效选择） | 不启动系统音频流，不注册设备 |

首轮配置失败：本机未安装 Ninja。保留失败日志，改用已有 VS 的 NMake，在独立构建
目录成功；没有删除原目录或安装新的全局工具。源码复核后将适配器定位改为先走
DeviceTopology、再查 PnP，防止把软件端点节点直接当成驱动归属；重编译及上述 3 项
回归通过。没有隐藏初次环境错误或放松测试断言。

本机工件：源码外 `artifacts/2026-11-07/audio-endpoint-001/`，含实验定义、构建日志、
CTest 原始日志、安装进程前后快照、验收 JSON 与摘要。先前 `3c02b2f` CI 日志再次
下载返回 EOF；保留原始错误，不重复构建来代替证据，也不将预期 67 项填作日志实测。
本轮 CI 结果在推送后另行登记。
