# AV-E7b 虚拟摄像头生命周期接口

## 目的和边界

假设：已有 CameraSession 可经固定 C ABI 接到原生主进程，同时保留取消优先、
独立撤销、线程归属和失败资源保留。决策价值是确定主窗媒体启动可否建立在此
设备层之上。断言失败即定位，不削弱测试；本机不重复执行被防护清除的程序。
影响产物为自有视频输出 DLL、Rust 绑定与 Windows 验收账本。

本轮起点 `2a8f3fb`，独立分支 `feat/windows-eye-output-20261107`。保留教育、
实时辅助和眼部路线，完整数字人仍冻结。没有真实采集、声音播放、SDK 执行、
设备注册、安装或防护变更。360 已有测试 EXE 清除记录，本机静态检查与 CI
结果分别记录，不能将阻断原因已明确解释成误报已确认或防护兼容已通过。

## 实现

- 在原有 `TingXianVideoOutput.dll` 增加 `TxDeviceAbi=1`；仍为四组件随包。
- 创建无副作用，显式启动仅接受同步 v2 端点；拒绝 v1、工作进程 v3、缺失意图。
- 单实例单次启动；创建时保存取消票据，排队启动也受先到停止约束。
- 回调在慢 OS 调用结束前撤销会话，开始/停止/销毁限定创建线程。
- 清理失败保留实例和回调，区分原始故障与清理故障，允许明确重试清理。
- Rust 复用固定摘要/文件租约加载器；绑定具体 Input，禁止外部传端点。
  取消句柄在销毁前失效；未确认清理的 Drop 保留库与上下文直到进程退出。
