# 截图预览与单次发送

2026-11-08，R07 源码候选。未替换安装版，未采集真实屏幕或调用视觉 API。

## 使用

面试工作区点击「截屏答题」→选择题目所在屏幕→「截取预览」→「发送并回答」。只有最后一步进入现有视觉回答通道；预览不创建回答卡、不增加模型调用数，也不占三路文字回答位置。

可勾选「下次快速发送」：本次确认发送之后，同一屏幕配置下再次点击主按钮会重新截取一张图片并发送。旁边的「预览」始终可用于改选屏幕或关闭快速发送。偏好可以保留，但每次重新打开工作区仍先确认一次。显示器 ID、尺寸、主屏信息发生变化，或原生权限预检要求确认时，回到预览。没有持续、定时或自动背景截图。

预览只保留在主窗口与原生内存中，最长五分钟、同时一份、发送后不能复用。图片不写入会话、恢复草稿、导出包或展示窗口。会话记忆沿用既有「图片未持久化」与资产摘要契约；再次需要原图时重新截取。

## 实现边界

- `ScreenshotControl.tsx` 持有短期预览状态；本机偏好只有屏幕 ID 和快速发送开关。图片绑定随机问题 ID、当时问题、最近三轮问题、十二条实际发言和参会模式。回答流版本在确认发送时分配，连续截图不会固定为版本 1。
- `interview_screenshot_preview.rs` 提供主窗口专用的创建、取消、确认命令。原生保存图片与上下文哈希、屏幕列表摘要及无凭证的视觉配置摘要；确认时消费一次性标识，重新检查权限、屏幕、配置和有效期。图片仍走原有 PNG/10 MiB 校验与完整请求预算，不改冻结的模型装配代码。
- 新对方完整发言、编辑问题/模式、清空/取消、会话恢复或退出会使旧预览失效；晚到截取与旧取消不会覆盖新图。取消可在创建 IPC 开始前登记，避免异步乱序重新打开旧截图。
- 发送时采用截取时的近期实际发言，事实、来源、检索及会话记忆仍按发送时有效版本核对。图片绑定不绕过撤回，不冻结旧资料的外发权限。旧直接截图 IPC 为兼容保留，新工作区不再调用它。
- macOS 本次显式截图通过 ScreenCaptureKit 排除本进程窗口，避免预览面板挡住题目。这不是控制飞书等其他软件的共享范围；实际截图效果仍待实机验收。权限只读检查使用 [CGPreflightScreenCaptureAccess](https://developer.apple.com/documentation/coregraphics/cgpreflightscreencaptureaccess%28%29?language=objc)。
- 本轮不更改 Windows GDI 捕获实现；Windows 同屏面板遮挡、真实双屏和权限行为需在后续跨平台合并时单独处理与验证。屏幕摘要是系统显示器 ID/尺寸/主屏信息，不是硬件身份认证，也不保证识别两次检查之间所有瞬时连接变化。
- 三路文字回答、独立视觉位置、实时 `legacy`、AI2 默认关闭、四角色离线和 Harness² 关闭保持原样。完整开发 XML 不加载到实时提示。
