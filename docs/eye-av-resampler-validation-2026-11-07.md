# AV-E1 原声重采样与同步窗口交付

本轮沿用 `feat/windows-eye-output-20261107`，起点 `30e283b61bf9e7557bc99772437629eb807dcae5`。
接续[时间线第一部分](eye-av-timeline-validation-2026-11-07.md)，目标仍是
[原始音视频、眼部校正及同步虚拟设备输出](eye-av-sync-scope-2026-11-07.md)，
不是仅做 ASR 或单路视频。教育和实时辅助保留，完整数字人/TTS/代理冻结。

## 假设、决策和停止条件

假设：按共同时间线的绝对采样位置使用带限插值，可生成连续原声 PCM，不引入另一套
累计漂移的相位；将滤波前瞻纳入已有缓冲后，音频和视频标签仍指向同一采集区间。
决策价值：固定 WASAPI 端点适配器实际接收的 PCM/视频交付接口和滤波边界。
停止条件：相位错误、频带明显失真、旧输出泄漏、意外单路输出或无界缓冲先定位修复。
影响：本机原生滤波和交付核心；不证明虚拟麦克风、会议接收、真实听感或稳定安装版。

## 实现与接入边界

新增 `av_timeline/render.rs`，复用已锁定的 Rubato 0.15.0 公开 `ScalarInterpolator`。
实际取得 52797 bytes 源包，SHA-256
`b5d18b486e7d29a408ef3f825bc1327d8f87af091c987ca2f5b734625940e234`，与原 Cargo.lock 一致。
只为原生控制库增加该版本依赖，不升级其他版本；该依赖不主动开启 FFT 或日志功能。
实际 MIT 许可及版权已完整保留在 Windows 随包 `THIRD-PARTY.md`，准备脚本原有复制路径
仍适用。[库文档](https://docs.rs/rubato/0.15.0/rubato/)与实际包源码核对；网页无法返回的
低层接口页改由已验摘要的官方 crate 源码核实，没有采用第三方整合包。

- 256 taps、256 个相位、BlackmanHarris2、截止系数 0.94。只补偿 48 kHz 单声道的
  受限设备时钟漂移；44.1 kHz、立体声等采集格式转换仍须端点适配器单独处理。
- 显式补偿内核相位原点。中心滤波需要 128 个后续样本（约 2.67 ms），必须在现有
  40 ms 实验同步缓冲内已取得；不额外偷偷把输出时间移动半个滤波器长度。真实设备
  缓冲/消费延迟仍需测量并纳入排期，40 ms 仍非产品承诺。
- 保存流的原始样本起点，只在采集开始之前补零。中途缺失、已退休或尚未取得的样本
  不能补造、重复或拼接旧声音。历史保留改为至少 3 ms 加完整锚点，支持小包/短周期；
  编译期约束防止日后滤波长度超过保留范围。
- 单调采样位置游标避免每个输出样本反复扫描全部包。固定容量工作区：1248 个 f64
  输入位置、960 个 f32 输出样本；滤波核在回调之前构造，处理不新增 heap 音频缓冲。
  临时 PCM 只在交付作用域存在并逻辑清零，不声明抗内存取证的物理擦除保证。
- `with_rendered_window` 在同一代次/停止锁下交付 PCM、校正视频、采集及预期呈现时间。
  滤波欠载时交付全零音频和 `video=None`（中性画面），明确标记 MissingFilterInput；
  缺时间线输入单独标记。只有实际媒体交付才增加媒体计数，滤波欠载独立记账。
- 下游必须整体接收或拒绝两路窗口，且不能阻塞/重入。拒收或异常使时间线清空并故障。
  单次回调不是两个真实设备的原子提交；端点所有者仍须完成预留、截止时间重查、停止
  撤销、硬件缓冲清理及看门狗。此 API 没有创建设备、打开麦克风或接入 Tauri 主窗。

## 本机结果

Windows 11 Pro 10.0.26200、Ryzen 7 9700X、RTX 4070 Ti SUPER/32.0.16.1088；
Rust 1.99.1 / MSVC 19.29。构建/工件和下载在 D 盘。GPU/SDK 不参与本轮执行。
命令为 `cargo +1.99.1 test -p video-worker-control --locked av_timeline:: -- --test-threads=1 --nocapture`。

前置只增加依赖时原 17 项通过。首轮滤波新增 7 项与原 17 项共 24/24 通过；
检查夹具时把预装输入的时间调整到实际输出之前，并补充 1 ms 输出退休边界后，
最终 **25/25 通过（原 17 + 新 8）**。原生库其他 42 项被过滤，不计为本机通过。
没有降低既有断言或阈值。旧测试中显式注入的 sink panic 已捕获，属于预期故障案例。

| 预先固定的判据 | 实际观测 | 覆盖限制 |
| --- | --- | --- |
| DC 误差 <0.0001 | 通过 | 一种幅值及测试相位，不是所有设备电平范围 |
| 1/8/18 kHz 相对 RMS 误差 <0.001 | 0.00000005 / 0.00000211 / 0.00001049 | 合成 48 kHz 波形，不是人物听感或完整频响扫描 |
| 23.9 kHz 衰减 ≥60 dB | 143.637 dB | 单一近 Nyquist 测试点，不能推广为全阻带保证 |
| 脉冲中心误差 ≤1 输出样本 | 峰值 80，对照 80.000000 与 80.177600；时间标签仍相差 40 ms | 证明滤波相位补偿，不证明端点/会议延迟 |
| 不同包长/输出分块一致 | 48/480 输入包、整块/分两块输出逐样本相同 | 不涉及网络/驱动格式变化 |
| 持续漂移实际 PCM | 两个各模拟 10 秒的 1 ms/10 ms 输入案例，各 995 就绪窗口，相对 RMS 0.00000005 | 模拟时钟，非 10 秒实测采集；未播音 |
| 有界与短周期 | 两案例 PCM 峰值 2544/2400 帧；1 ms 输出周期保留滤波历史通过 | CPU 实时调度、抢占/并行 SDK 负载另测 |
| 欠载/停止 | 缺前瞻两路中性/静音，旧区间不补播；拒收及三次重启不复用旧滤波 PCM | 真实端点的 stop/reset/drain 尚待接入 |

模拟漂移测试的本机 debug 总墙钟时间约 4.37 秒，包含两套测试循环，不能当作单块延迟
或生产实时性能。原模拟 600 秒时间线回归也在同一次运行通过，但不冒称 600 秒真实
音频处理或会议验收。完整原始日志保存在源码外 `artifacts/2026-11-07/av-resampler-001/`。
