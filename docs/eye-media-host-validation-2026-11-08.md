# AV-E5d 主进程媒体所有者

基线 `0c0c1c60209a99fffaab9556a9569d519539498d`，独立分支
`feat/windows-eye-output-20261107`。本轮接续共同输出所有者，不启用真实采集。

## 实验与实现

- 假设：原生媒体专属线程能保持共同输出的线程所有权、有界连续 PCM 和准确的
  退出确认。决策价值：决定主进程能否接入生命周期，而不让 WebView/异步执行器持有设备。
- 停止条件：跨线程设备调用、无界/静默替换原声、旧源/旧代次准入、停止新来源、
  未清理却报告正常退出，或需启动未经授权的真实设备。影响：原生 Host、主窗退出契约。
- `joint::host::Host` 默认不启动；显式原生配置、当前代次和同一 Controller/来源租约
  才能创建线程。JointOutput 的准备、消费、停止、释放均在该线程内。
- 原声入口最多 2400 个单声道样本（48 kHz 下 50 ms）及 16 包；只准入选中的本人
  麦克风来源。超限故障并清空，不能将语音任意替换为最新一包。Timeline 的独立上限保留。
- 停止立即撤销入口/未领取端点、清空 PCM，并按身份停止绑定 worker。旧 Input 析构
  不能停止同一 Controller 的后续来源；源停止与入口准入共享短期租约锁，不等下一轮 tick。
- 实际线程退出、音视频清理和绑定 worker 退役后才返回本地 idle；超时不允许重启，
  Reset 错误不被取消退出/恢复操作抹掉。外部接收端排空仍未知，原持久重启屏障保留。
- Tauri 主窗口的停止、退出准备和取消退出纳入 Host；展示窗仍无管理权限。没有新增
  WebView 同步启动命令、物理捕获、虚拟设备注册或自动恢复输出。
