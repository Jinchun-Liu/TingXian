## 当前实现与兼容

`request_budget.rs` 在协议字段装配之后计量完整序列化请求，包含工具、schema、消息封套和转义；基于实际 max_tokens 预留。每次发送/重试前再准入。图片数据不按 base64 长度冒充 tokens；未知图片在文字达到硬输入预算 75% 时阻止发送，低于此线仍只代表文字部分检查，沿用未知警告。可裁剪项只包括可选检索与旧上下文；当前题、事实、冲突、最新两条发言和图片保留。模型能力未知不等于已核对服务商窗口。

`session_memory.rs` 保留稳定逻辑序号、不可变修订日志、采集/发言来源和问题版本。快照最多 64 条/64 KiB，只选择已结束旧边界并留下最近 12 条；正常追加不使快照失效，旧修订和依赖变化会失效。原文回放与按需工作集分开；来源版本不匹配的派生片段不会从记忆或原文检索绕过撤回。截图保留资产 hash 与原始条件，不假称读取过图片。

候选只接受带精确引用的整条原文摘录，可合并相同 kind/origin/text 的引用；不能省略原始发言、本人确认或截图条件。AI 建议和规范化问题可带原因省略；失败答复不可晋级成已完成结论。这是保守抽取/索引，不是已验证的自由语义改写压缩。含否定、SQL、金额和未完成经历的原句逐字核对；不能用 JSON 有效证明自由摘要保真。原始日志始终保留。

`compaction.rs` 独立 id 为 compaction，不改变 answer-1/2/3。配置默认关闭；控制器要求发送许可、前台空闲、每会话单飞、至少 16 条、60 秒冷却，默认最多 8 次和 200000 单位本地预留预算。该额度是输入 UTF-8 估算加输出预留，**不是新消费授权或人民币预算**。未知 usage 保留预留占用，实际用量不把推理/缓存重复累加；同快照失败不自动重复。候选至少减少 256 序列化字节且达到 10% 才尝试晋级，此门槛衡量结构大小，不能称 token 或费用收益。传输零自动重试、单次 60 秒截止，异常终态和取消不晋级。源码控制器的前台优先信号尚待原生三路调度器实际接线。

`memory_store.rs` 在宿主传入的已有会话数据库中增量建三张 tingxian_memory_* 表，不另开数据库。每条原文提交后返回 hash/序号 ACK；重复 ACK 幂等，不能越过未保存前序。单事件约 84 KiB、单会话 20000 次修订/32 MiB、总 200 会话/128 MiB 为逻辑负载上限，不等于物理磁盘占用。读取分页验证 hash、身份、顺序和覆盖缺口；v1 恢复必须明确传入缺失历史标记。原生清空把三表纳入同一可读回废纸篓归档，失败不清库，普通退出保留；清空后的旧 epoch 不能回写。真正磁盘满未制造，测试使用事务失败注入。
