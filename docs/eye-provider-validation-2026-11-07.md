## 实现与决定

新增 [video/eye](../video/eye/README.md)：可替换 `EyeCorrectionProvider`、独立输出
sink、显式准备/停止和最多两帧等待队列。入口接受 BGR8 离线帧，不含摄像头、音频或
云调用。停止先撤销输出，再由工作线程清理；旧代次初始化/结果不得回填。错误、
丢脸、畸形输出或 sink 拒绝会中性化并停止，不回退原图，不自动重新开始。
清理状态不明时，该进程禁止重启，应交给宿主监督器结束。

旧版 Ada 适配器是默认关闭的显式实验构建选项。固定官方 0.8.7 头文件和本地审阅
的运行时路径/摘要，加载前加锁校验，限制 DLL 搜索并检查 ABI。C 桥接避免头文件
C++ 隐式构造调用未固定的代理入口。每次结果需完成 GPU 同步，错误不会沿用旧输出。
没有下载/复制 NVIDIA 二进制或模型到源码、CI 或发布包。

假设：该边界可以独立于具体 SDK 保证队列有界、停止隔离和失败中性化；决策价值是
能否接入已有受监督 worker。任何原图回退、旧帧回填、无界积压或不安全加载都停止
采纳并定位根因。影响产物为 provider、worker 设计和 Windows 验收账本。

## 本仓库合成验证

Windows 11、VS 2019 MSVC 19.29、CMake 4.4.5，SDK-free Release 测试通过 **137 条断言**。
全部使用本仓库 fake provider 和合成字节，不调用 NVIDIA、不拍摄、不录音：

- 默认关闭、显式准备、运行时不可用和部分准备清理。
- 两帧队列上限、准确丢弃计数、帧长度/ID/代次/时间戳拒绝。
- 处理前后过期、返回畸形数据、异常、丢脸、推理失败和 sink 拒绝。
- 准备/推理/清理过程中停止，旧启动票据和迟到成功结果隔离。
- 三轮显式重启、清理失败后不可重新开始，有限并发交错检查。

新增 Windows/Linux 独立 CI，仅构建上述合成检查；本段不把新建 workflow 当作已经
运行通过。CI 状态在取得实际运行结果后另记。
