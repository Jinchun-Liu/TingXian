# AV-E5c 眼部流与共同输出生命周期

基线 `ac35f07111e582b30fcb6ee7b0d514ded24188f9`，独立眼部分支。
接续 [QPC 宿主接收](eye-qpc-host-validation-2026-11-08.md)。本轮打通原生控制层的
校正结果到共同输出所有者；没有启用摄像头、麦克风、SDK 或已安装虚拟设备。

## 假设与决策

假设：独立接收线程能把固定眼部 worker 的校正结果交给共同输出所有者，来源失效时
撤销两路输出，同时不把最长 500 ms 的管道读取放进音频设备线程。决策价值是验证
原生接线与生命周期边界，为实际输入和宿主接入提供依据。停止条件：原画面回退、
旧代次输出、无界积压、停止锁内等待设备、DLL 生命周期竞态或提前声称清理完成。

## 实现边界

- `JointOutput::bind_corrections` 只允许开始前绑定一次；绑定后拒绝手工提交视频，
  不留原画面绕过入口。来源控制器代次与共同输出代次分别验证，不混用。
- 独立 reader 线程使用一个最新校正帧槽；新帧替换尚未领取的旧帧，计数可查。
  保留原采集 QPC、完成 QPC 与 ID；交接和设备提交前再次检查 250 ms 原采集租约。
  首个有效结果之前不预热/启动音频，首帧上限 2 秒；超时共同撤销。
- worker/reader 失效时，先清空槽位、撤销视频并唤醒所有者。音频客户端仍只由
  所属 MTA 线程调用；该线程清空待提交 PCM/时间线、停止两路，再有界退役 reader。
  包读取上限 500 ms，退役等待上限 1 秒；不在停止租约锁内等待管道或设备。
- 明确区分停止请求、已经准入的所有者操作和已确认清理。停止请求可能与一个已
  准入操作竞争；这不是跨设备原子事务。无法撤回已经交给外部的画面或声音。
  reader 未退役保留清理错误；外部排空未证实，持久重启屏障仍保留，不提供绕过。
- 跨线程取消仅持有受互斥锁保护的 `TxTimedCancel` 指针；DLL/实例销毁前使其失效。
  不开放其他跨线程设备操作，避免回调在实例或 DLL 释放后使用旧地址。
- 一个手动重置事件唤醒共同 owner；停止事件仍优先，设备循环最多等 5 ms。
  这不是实时调度保证，实验中的固定延迟也不是会议接收端同步测量。

## 本机验证

Windows 11 10.0.26200、Rust 1.99.1、MSVC 19.29 / SDK 19041；D 盘隔离工件。
本轮重新编译视频测试适配器，原生音频内存 fixture 与 SDK-free 眼部 worker 复用已
验证版本并核对摘要。没有物理采集/播放、驱动注册、安全设置改变或应用升级。

| 回归 | 实际范围 |
| --- | --- |
| joint 27 项 | 7 项新增来源/清理检查、1 项停止错误传播，原有共同输出 19 项 |
| timed_video 6 项 | 包含跨线程撤销及实例/DLL 释放后令牌失效 |
| eye_qpc 8 项 | 来源 ID/时间、报文、过期、停止与有界记录 |
| stream 18 项 | 原有输入、旧预览、重启、MF 及协议版本 |
| 原生视频 CTest 5/5 | 未注册源、跨进程像素/时间、排期及校正输出 |

上述 Rust 筛选合计 59 项独立测试。真实子进程合成 NV12（Y=188、UV=128）经过
reader、Timeline、异步桥到独立 MF 消费者，逐项核对原 ID/采集时间/排期 PTS；
配套内存音频核对 960 个交错样本均为输入 0.2。不是录音、扬声器或虚拟声卡测试。
覆盖停止发生在音频提交前/提交后、provider 失败、帧过期、无首帧、半包读取期间
停止、单槽替换及手工绕过拒绝。停止请求本身不冒充音频/reader 清理确认。

继续复核复现了既有停止路径的错误：音频 Reset 失败时仍返回 `Ok(Stopped)`。
现由共同清理结果传播原始 HRESULT，设置 Fault，保留其余清理结果及重启屏障；
不把单路失败隐藏在成功状态内。修复首轮误将“尚未领取的取消回执”当作媒体积压，
原正常停止用例因此失败；核对 C++ 取消/停止/领取语义后改用完成退役的 local_clear，
保留回执，原断言不改。失败与最终 27 项回归日志均保留。

首次编译发现整数条件和枚举比较类型错误，第二次发现测试模块引用错误；原日志
保留，修正后运行通过，没有降低断言。CTest 首次筛选仅匹配 1 项，补跑另外 4 项，
没有把一次绿色退出误报为全套通过。CI 结果另行回填。
证据在 `artifacts/2026-11-08/eye-joint-001/`：实验、失败与成功日志、构建脚本、
输入摘要、环境/保护状态和校验清单；不把本地用户路径或媒体放进公开二进制。

早期安装进程检查点一致；11:57 再查已无听弦进程，但安装文件仍在。未执行退出、
升级或重启，消失原因未确定，不能报告进程持续运行。硬件详情沿用同日记录，
本轮 CIM 收集未完成；系统版本与磁盘空间另行实测。证据脚本最初因时间字符串
小数位和旧清单结构差异失败，改为比较时间值并读取明确的清单字段，仍逐项校验
原生输入大小/摘要，不以元数据格式差异隐藏实际现场变化。
