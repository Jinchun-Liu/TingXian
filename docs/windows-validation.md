# Windows 验收与交接

本文件记录 0.7.0-beta.1 的验收边界。源码基线为 macOS 0.6.5 `f80ba86`。Windows 安装包是测试版，发布物必须来自 `.github/workflows/windows-preview.yml` 的成功运行。

## 自动验证

CI 检查 CPU 构建、前端回归、Rust 核心、固定摘要的随包资源、真实安装、自带 Python/DOCX/PDF/Whisper/FFmpeg、数据库迁移与恢复、卸载保留合成用户文件。运行链接和提交号在发布说明记录。2026-11-05 的构建 `d888e6156201636d1494c4387da295d66095ba1d` 已通过这些检查，并通过合成回收归档核对及 CI 桌面内存截图检查：[运行记录](https://github.com/Jinchun-Liu/TingXian/actions/runs/41999633117)。实际音频设备、GUI 交互、旧版升级、双屏与长通话仍未验收。

截图实现使用 Windows GDI 按显示器捕获，保持比例、最长边 4096、限制 10 MiB，返回内存 PNG。仅用户触发时工作。取消后不发送结果。系统输出使用 CPAL/WASAPI loopback，麦克风走独立流。手选设备必须精确匹配，不能静默替换。

## Windows Codex 续作顺序

1. 读取本文件、`docs/PRD-v2.0.md`、`docs/PRD-v2-progress.md` 以及私人仓库中的交接文档。
2. 核对 public 仓库分支和发布资产 SHA-256，安装测试版。记录 Windows 版本、CPU、内存、GPU/驱动、音频设备和网络区域。
3. 先关闭 AI 外发，只做系统音频和本人麦克风短测。对端说“StockMarketAgent 的契约测试如何区分 null、零、缺失字段和空字符串？”本人说“我会分别检查 JSON Schema 和业务语义”。核对来源及零 AI 调用。
4. 停止再启三次，清理历史再开始，保存并重启恢复。检查用户资料与偏好。
5. 配置使用者自己的 API。三题并行、第四题排队、取消其中一题、对方追问本人实际回答、断网/429/超时、迟到事件均不能串题。
6. 多屏截图预览、取消、发送、视觉结果以及屏幕拔插。浏览历史时新字幕不抢位置，返回最新答复恢复跟随。
7. 分别测试默认/手选输出、USB/蓝牙、采样率切换、同名设备、拔插、麦克风权限拒绝。记录真实声源而非仅记录“流创建成功”。
8. 用合成资料验证文件夹/单文件导入、DOCX/PDF/JSON/YAML、Skill 导出回导、清理失败不丢资料、Windows→Mac 兼容。
9. 飞书双设备、耳机、摄像头 30 题/60 分钟。含 PRD 的两分钟长题、本人回答后追问、停止/恢复。保存全部失败与超时样本。
10. 另在没有高端独显的 Windows 机器完成安装与短流程，再决定能否移除测试标签。CUDA、数字人、虚拟摄像头属于后续独立阶段。

## 每轮报告

记录版本/commit、安装包摘要、Windows/硬件/驱动、模型 ID、API 区域、资料版本、逐题原文和结果、发言结束与 final/首句时间、资源占用、失败恢复、截图/录屏路径和未测项。不得把 CI 编译、合成回归或 Mac 的既有结果填成 Windows 实机结果。

发布目前不包含自动上传会话或密钥的诊断功能。提供反馈前由用户检查材料。任何 Key 都在对应机器本地配置。
