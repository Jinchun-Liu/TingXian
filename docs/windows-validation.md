## Windows Codex 续作顺序

1. 读取本文件、`docs/PRD-v2.0.md`、`docs/PRD-v2-progress.md` 以及私人仓库中的交接文档。
2. 核对 public 仓库分支和发布资产 SHA-256，安装测试版。记录 Windows 版本、CPU、内存、GPU/驱动、音频设备和网络区域。
3. 先关闭 AI 外发，只做系统音频和本人麦克风短测。对端说“StockMarketAgent 的契约测试如何区分 null、零、缺失字段和空字符串？”本人说“我会分别检查 JSON Schema 和业务语义”。核对来源及零 AI 调用。
4. 停止再启三次，清理历史再开始，保存并重启恢复。检查用户资料与偏好。
5. 配置使用者自己的 API。三题并行、第四题排队、取消其中一题、对方追问本人实际回答、断网/429/超时、迟到事件均不能串题。
6. 多屏截图预览、取消、发送、视觉结果以及屏幕拔插。浏览历史时新字幕不抢位置，返回最新答复恢复跟随。
7. 分别测试默认/手选输出、USB/蓝牙、采样率切换、同名设备、拔插、麦克风权限拒绝。记录真实声源而非仅记录“流创建成功”。
8. 用合成资料验证文件夹/单文件导入、DOCX/PDF/JSON/YAML、Skill 导出回导、清理失败不丢资料、Windows→Mac 兼容。
9. 飞书双设备、耳机、摄像头 30 题/60 分钟。含 PRD 的两分钟长题、本人回答后追问、停止/恢复。保存全部失败与超时样本。
10. 另在没有高端独显的 Windows 机器完成安装与短流程，再决定能否移除测试标签。基础 CPU 包不强制 GPU；虚拟摄像头与仅本人原声的虚拟麦克风进入 R10E 同步阶段，独立核对设备安装/来源/停止及接收端同步。脸部/TTS 和旧数字人继续后置或冻结。
