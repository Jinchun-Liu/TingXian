## E04：本地无声出画续测

决策问题：固定版本 LivePortrait 核心在本机能否生成受控头姿/眨眼帧，并在 40ms 帧预算内留出后续音频和输出余量。先做 10 秒短序列；失败保留日志，明显不适合时停止该路径，不直接启动 30 分钟压力测试。

新增官方 LivePortrait 源码 `9b294b3d0536135442ea73cb01e6cb3ca7029dd3`；权重 revision `82a4fa6735ca58432b6ce39301b4b9ee066dea47`。现有 ONNX Runtime 仅 CPU provider，因此选 PyTorch CUDA 核心出画、CPU 单次关键点注册，未把 CPU 渲染冒称 GPU 路径。没有使用 InsightFace 检测器；输入为已准备好的方形正面肖像，此限制不能推广为任意用户照片已经可用。

SD-Turbo 固定 revision 在本地离线生成虚构肖像，无真人输入、无提示词外发。首张构图过近，保留为 `synthetic-portrait.png`；第二张完整头肩构图为本轮对照输入 `synthetic-portrait-02.png`，SHA-256 `b0c8e079a93bba473f79c97ad7c64a053b57f167cc39bfdd31ccdb38d19dbc3f`。这是测试素材生成，不是个人数字形象创建功能已经完成。

E04b 的 cuDNN 对照用于判断固定尺寸卷积的算法选择能否省去更换后端；一次同素材对照后停止，不基于这组未重复统计的短测宣称普遍加速。

E04c 是计时边界修正：复查发现 probe-02/03 把 PNG 落盘计入总墙钟，原报告字段名过于宽泛。保留两份原始 JSON/CSV，不改原始数字；修正后只复测一次默认配置，确认是否应立即更换后端。25fps 门槛、250 帧、输出尺寸、编码参数与控制序列均保持，最终仍未达标，停止同路径短测。后续必须记录计时范围，不能将取证开销或文件标称帧率混为模型/会议性能。

收口审阅补齐失败取证边界：若渲染先失败、编码器随后在关闭时也失败，旧清理路径可能覆盖原异常并跳过报告落盘。现在分别保存原始错误与 `cleanup_error`，最终仍返回失败。`check-render-failure-evidence.py` 在本地证据目录注入“渲染+flush 双失败”和“仅 flush 失败”，两项均保留原错误、JSON 和已处理帧 CSV；未使用 GPU、采集或播放。这是错误处理回归，不追加性能成绩。

三份成功 MP4 均经 PyAV **实际解码**核验为 512×512、250 帧、连续时间戳、10.0 秒且 **0 条音轨**。视频是离线产物，没有连接虚拟设备或会议。`encoded-validation.json` 区分文件帧率与生成吞吐。

人工可视检查（助手查看抽帧）：`neutral.png`、帧 40/80/195 可见两眼闭合、恢复和头部转动，人物外观与背景基本保持。尚未完成连续视频自然度评审；固定测试序列的周期动作不作为产品自然待机算法。没有眼神方向控制、身体跟踪或原声口型，适配器能力表相应为 false。

模型下载目录在 D 盘。`avatar-prepare-runtime.py --verify-only` 对 LivePortrait 7 个文件和 SD-Turbo 14 个文件逐一校验大小与上游固定版本的 LFS SHA-256 / Git blob 摘要，**21 个全部通过**；摘要记录 `model-manifest.json`。候选模型和三份成功无声视频均未上传公开仓库。

同日补查近期项目：OpenSpline、PersonaLive/EditaLive、AvatarForcing、Audio2Face-3D、Talking Avatar 与 Meta Muse 的官方材料已进入研究报告，均属于资料审阅，未计作部署成功。EditaLive 学术用途限制、AvatarForcing 许可冲突保留为不接入依据；3D 可控路线只增加下一步 E07 决策实验。

实际调用的核心包：torch 2.11.0+cu130、torchvision 0.26.0+cu130、numpy 2.4.4、opencv-python-headless 4.13.0.92、PyYAML 6.0.3、scipy 1.17.1、onnxruntime 1.24.4、av 17.0.1、Pillow 12.2.0。素材生成另用 diffusers 0.37.1、transformers 5.5.4、safetensors 0.7.0、accelerate 1.13.0；下载器 huggingface-hub 1.11.0。这是已运行版本记录，不是全新环境安装验收。
