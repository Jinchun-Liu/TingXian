## 发布口径

Windows 目标机接手记录：[2026-11-05 首轮及续测](windows-local-validation-2026-11-05.md)。原防护状态下关键 DLL 创建被拒绝；WPR 已确认 360FsFlt 前置回调返回 `STATUS_ACCESS_DENIED`，具体产品规则仍未取得。用户主动退出 360 后，原包以普通用户权限安装至 D 盘，876 项摘要与离线自检通过；360 主进程恢复运行后复核通过。电脑插件在新一轮调用恢复连接，原安装版已验证 small 就绪、五份中文合成资料恢复与本地检索、单屏拆窗合体和空会话正常退出；音频/AI 外发始终未开启。工具子进程的 AppData 备份被发现重定向至代理缓存，已更正证据范围，并通过 Explorer 取得实际索引副本核对。

源码修正 Windows 提示及 NSIS 文件失败仍报成功的问题；`fb5b8f7` 的 [新包 CI](https://github.com/Jinchun-Liu/TingXian/actions/runs/42027994092) 全部通过。在本机 360 主进程运行时，新包普通用户安装正确退出 2，未完成安装；失败处理修复通过实机验证，**原防护状态下完整安装与修正后 GUI 仍未通过**。CI artifact 没有覆盖原发布资产。含对话的保存退出、真实音频/AI、多屏和长会议仍待验收。

R01 续作 `2dd84b3` 修复保存失败时丢失输入，并给显式快照增加独立输入草稿；[Windows CI](https://github.com/Jinchun-Liu/TingXian/actions/runs/42046598824) 的 22 组前端、50 项核心及新增数据库恢复自检通过，新包已下载到 D 盘并校验。目标机新包安装/GUI 尚待；正常退出、工作区切换及崩溃自动恢复另行收口。用户暂不处理 360 厂商反馈，未发送或上传材料。

Mac 0.6.5 的安装和短测证据已有记录。Windows 首版按 PRD 标为测试版。云 ASR、数字人、自动代理和完整长会议验收尚未完成，各自有独立门槛。阶段推进不把这些项目删除，也不以 Windows CI 成功替代实机验收。

数字人独立阶段：[2026-11-06 研究与选型](avatar-research-2026-11-06.md)、[验证记录](avatar-validation-2026-11-06.md)。用户优先模拟面试与练习，当前保持采集/播放/真实 API 外发关闭。已有协议组件和独立离线渲染适配器，没有接入 GUI 或安装包，个人形象创建及 R11 全程代理仍待实现。
