# PRD v2 实施账本

基线为听弦 0.6.5 `f80ba86`，本轮按用户指令推进 Windows 测试版并提供跨设备交接。完整 PRD 见 [需求文档](PRD-v2.0.md)。文档里的“本次只产出需求文档”描述原 PRD 编写轮次，本轮已获得开发和发布指令。

| 范围 | 本轮处理 | 尚需证据/后续实施 |
| --- | --- | --- |
| R01 稳定性 | 保留停止/恢复、保存迁移、旧事件隔离，扩展 Windows 安装自检 | 两平台 30 题/60 分钟完整实机报告，崩溃草稿恢复 |
| R02 云 ASR | 记录接口与来源隔离要求，保留本地 small | 一个大陆供应商真实接入、账号、重连/降级、30 段配对延迟 |
| R03 问答/并发/阅读 | 现有 21 组前端回归通过，跟随与三路边界保留 | 20 短+10 长+5 代码题真实质量与限流测试 |
| R04 背景/Skill | Windows 包内置 Python 和文档依赖，原格式兼容 | 任务持久化/断点续作、增量冲突、两个真实 Agent 回导 |
| R05 256K | 继续沿用 262144 应用预算 | 精确模型能力、接近/超过预算和小窗口模型验证 |
| R06 多人 | 保留五模式、本人不触发、点名规则 | 100 标注样例、三人真实通话及误报/漏报 |
| R07 截图 | 新增 Windows 按显示器捕获、尺寸限制、内存 PNG、取消 | 双屏真实截图与视觉 API、模糊内容/权限拒绝 |
| R08 UI/拆窗/iPad | 保留品牌、20/80 布局、拆窗、字号、正文跟随 | Windows 双屏与 iPad 断开找回，窄窗巡检 |
| R09 Windows | 新增 CPU 安装流程、离线模型/文档/WebView2、WASAPI 精确设备、回收站清理 | CI 成功安装，再交 Windows 机器完成音频/截图/会议与无独显验证 |
| R10 本人数字形象 | 纳入路线图，独立模块边界 | 4070 Ti SUPER 原型、素材、虚拟设备、同步与帧率 |
| R11 授权代理 | 保留需求与来源/接管契约 | TTS、串行输出、打断、已输出记忆、30 轮与尾音测试 |
| 开源/生态 | 平台构建、许可、校验、可读接手材料 | 双语演示、公开音频评测、资料交换 schema、外部试用 |

公开仓库只包含代码、公开需求和合成测试。完整交接上下文与原始 PRD 存入用户私人仓库。原始对话中的 API Key 不进入任何交接或发布文件。

## 发布口径

Mac 0.6.5 的安装和短测证据已有记录。Windows 首版按 PRD 标为测试版。云 ASR、数字人、自动代理和完整长会议验收尚未完成，各自有独立门槛。阶段推进不把这些项目删除，也不以 Windows CI 成功替代实机验收。
