# 已应用设置的来源追踪

2026-11-07，接续 `5ae9fbb` 的 P2 实施。岗位、组织、背景、术语从背景建议应用后仍绑定当时的来源；来源修订、撤回、过期或清空资料库后，受影响字段不进入新的文字/截图回答请求。编辑框保留原值，供用户核对。

## 生效方式

- 四个字段分别绑定应用时的快照，新背景或另一字段的应用不会改写旧字段的依赖。直接手填且没有绑定的值继续使用。
- 普通保存只将实际改写的字段转为手动；修改语言或原样保存不能解除其他字段的来源保护。清空字段会解除空值的依赖。
- 用户可点击字段下的“转为手动设置”，显式保留原值。原生接口检查主窗口、采集状态、操作锁和当前值；过期请求不能解除绑定。
- 编辑器保存携带读取时的旧值，若设置已经被另一处操作修改，整次保存拒绝，不覆盖新设置，也不部分解除来源绑定。旧调用方省略 expected 仍兼容原协议；新版编辑器始终提供它。
- 来源记录位于现有 SQLite 的 `settings` 中，不另建库、不写回原文件。最多保留四份被字段引用的快照，共享同一快照时只存一次。资料清空后设置及依赖仍保留，失效值不会因索引归零重新启用。
- 云转写每次新建连接或重试都重新取有效术语，并与来源撤回共用网络读写边界。已建立连接之前发给服务商的参数无法撤回；本批保证后续新握手不重新携带失效术语，不声称删除了服务商已有内容。

## 验证

完整核心回归 89 项通过；最后对空值解绑调整重跑 7 项设置来源用例。原生 interview 回归 51 项通过、真实废纸篓用例仍忽略；最终 optional expected 接口再通过 15 项 interview IPC/边界测试。场景编辑、整体页面控制回归和 TypeScript 检查通过。

新增场景包括：撤回后的模型输入不含旧字段、各字段独立来源、手填值保留、语言变更不解除绑定、显式人工接管、旧编辑器快照冲突、过期与再核对、索引清空、事务失败回滚、旧格式和缺失来源。原生用例覆盖主/展示窗口隔离、会话锁、失效 expected，以及云转写新握手在撤回写锁后重新读取术语、取消时退出。

Chrome 使用真实组件和现有样式，连接内存模拟 IPC：字段原值可读、单独接管背景后术语仍待核对。截图在本机交付记录中。该验证不连接真实资料库，也不是安装版或真实云转写验收。

## 边界与后续

旧版本已存下但从未记录来源的设置无法可靠反推归属，继续兼容为原有用户设置；不伪造历史来源。自动合并的“术语别名”是另一个本地检索配置，本批尚未按别名行追踪来源。旧 AI 草稿继续保守失效。需要回退到不认识新来源记录的旧软件时，应先清空或人工核对这些派生设置，旧版不会提供本批的过滤保证。

四角色仍只用于离线准备/评审；实时按需装配，精简策略候选未晋级，Harness² 保持关闭。冻结 35 道文字题、12 道视觉题及 12 题口语候选输入源文件均未改变。语义岗位视图、故事卡、完整多源更新矩阵、真实模型质量、跨宿主回导、安装版及长会议继续待验收。本轮不制作安装器或更换运行版本；可移植候选包保持 0.3。

后续：本地检索别名的逐行来源已在下一批 P2 中实现，参见 [别名来源追踪](toolkit-alias-sources.md)；上述计数仍对应本批设置实现时的证据。
