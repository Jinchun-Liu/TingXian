## 恢复草稿实现记录（2026-11-06）

- 每秒合并变化写入独立 SQLite 草稿，正文、未发送输入、本人输入、用量和来源随快照保存。意外中断可能丢失最后一个检查点之后的内容；不承诺零丢失。
- 每次主窗口挂载使用独立 ID；启动只读目录，用户选择后才恢复正文。恢复将未完成请求改为已取消，关闭采集与外发授权，不重放请求或增加调用数。
- 退出先停止采集/请求，再等待最终草稿写入；写入失败保留窗口并显示重试。磁盘满不会每秒重复写入。
- 全量清空先归档草稿并核对可恢复副本，然后在同一事务删除并提升 epoch；迟到写入失败。退出的临时清理保留草稿。单份 16 MiB、总计 128 MiB/200 份，超过时保留旧稿并提示。
- 可复现页面夹具：构建 frontend 后运行 `node scripts/build-interview-recovery-fixture.cjs <新目录>`，只在 localhost 提供合成 IPC，不连接用户数据库或模型。普通/高级工作区均已通过 Chrome 可见恢复验证，布局保持操作在左、正文在右。
- 尚未安装本分支，不把浏览器/IPC 测试记为 Mac 实机长会议验收。

## 云转写实现记录（2026-11-06）

- 北京区百炼 Fun-ASR-Realtime，独立 Workspace ID/API Key；凭证只在主进程内存中保存，启动前显式勾选声音与术语外发，不借用文字问答授权。
- 系统输出和本人麦克风使用独立 WebSocket/任务/句子 ID。48 kHz 单声道 PCM16，原始缓冲在网络发送完成前持续计入 2 MiB/512 帧上限；超过上限停止采集并保留已收文字。
- 等待 task-started 后才接收音频；只有开始发送前的建连失败可重试一次。发送中断不重连或补传，停止时发送 finish-task 并限时接收最终句；取消立即关闭，降级由用户明确切回本地。
- 临时文字显示在独立字幕区域；完整对方句才进入自动问答，本人句仅进入上下文。麦克风关闭、暂停恢复、取消后的旧流受 epoch 和来源检查限制；迟到 partial 不覆盖终稿或已中断字幕。
- 云服务 usage 暂以原生事件记录供应商返回的任务累计秒数，尚未加入 UI 费用账本；不将其当作单句时长相加。服务时间戳异常时延迟为未知，不填零。

## 背景任务与 Harness 断点（2026-11-06）

- 每个桌面任务使用应用资料目录下独立的 `interview/background-jobs/<uuid>/job.sqlite`，不写来源目录。主界面只读列出任务，用户点击继续才调用 worker；Key 从当前接口内存补入，不持久化。
- 单文件/分块清单、已验证提取结果、归纳结果与请求尝试写入检查点；SQLite FULL 同步和进程锁确保不并发续作。创建请求记录失败时不发送请求。最多20个保留任务，单检查点约64 MiB，不自动删除旧结果。
- 缓存键包含输入和来源哈希，任务签名绑定模型/地址/规则/预算配置；来源变更重做对应文件，模型变化要求切回原配置或新建任务。每次恢复重新读取资料库当前允许外发的内容，不使用已撤销授权的旧检索片段。
- 完全相同的同批文件只提取一次，清单记录跳过原因；跨批资料语义去重/冲突仍需完善。整理末尾和应用前重核来源，变更阻止应用。参考答案仍不能当作个人经历。
- 用量区分已返回与中断未知请求；续作可能重发未取得结果的请求，UI 明确提示。不会将未知计量填零。完成的草稿可从任务继续核对，应用仍需人工点击。
- 移除任务只通过现有平台废纸篓/回收站接口；失败保留任务，成功不影响原资料和已应用索引。
- 导出 Skill 新增 `plan --root ... --cards ...`，报告当前来源下可复用与待处理批次；`pack` 延续 v1 资料包。Skill 静态校验、4组 Python 集成测试和页面任务状态测试通过。实际 Codex/Claude Code 安装回导、Mac 进程中断测试、生产页面视觉验证尚未完成。
- 提交 `f4c2859` 的 [源码与共享核心 CI](https://github.com/Jinchun-Liu/TingXian/actions/runs/42158539010) 已成功。此 workflow 没有编译 Mac 原生应用，原生新增命令仍需复核。

## 单请求预算（2026-11-06）

## 模型能力核对（2026-11-06）

- 基本回答接口和各独立位置均可记录文字、图片、流式、usage 的未知/支持/不支持，以及人工核对日期与来源。旧配置缺省为未知，不按模型名称猜测或自动外发测试。

- 固定文字连接测试不修改能力记录，也不能证明视觉或上下文上限。未知能力保持既有请求兼容行为；图片窗口仍单独标为未知，不宣称已通过真实视觉验证。
