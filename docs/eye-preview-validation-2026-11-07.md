# 原生校正帧预览接收验收

起点 `9842712`，独立 `feat/windows-eye-output-20261107`。教育分支 `ac958f6`、
眼部本地分支 `b00b63d` 和数字人归档 `2a80d7b` 原位保留，没有合并 Mac 后续开发。

## 决策与范围

假设：主进程原生处理通道可以消费真实子进程校正后的像素，保留原始身份和时间，
不注册摄像头也能为后续本地预览提供接收入口。决策价值是补齐主窗预览接入所缺的
接收器，而非把测试客户端当成产品接口。错认对端、原图回退、停止后旧帧、无限等待
或帧积压即停止扩展，先修根因。影响监督库、后续主窗接入及验收账本。

仅使用自有合成 Provider/像素。没有运行 NVIDIA、启动物理或虚拟摄像头、采集音频、
播放或外发媒体，没有执行安装器或更改防护。新 API 尚未接入 Tauri/主窗或安装版。

## 实现与已发现问题

- `StreamFeed::open_preview` 只消费所属流的单次端点。原生接收器核对服务进程 PID、
  Windows session 和能力握手，使用不可继承句柄及 identification-only 安全级别。
  端点、像素均不实现日志/IPC 序列化，不接受 WebView 指定 EXE、管道或凭据。
- 一份最新完整 NV12 和一份正在接收的定长载荷；核对格式、长度、代次、顺序及原始
  采集时间。过期/未来帧、断线、错误和停止均不给出旧像素，无原图回退。
- 使用者在原生通道轮询，未另建游离接收线程。部分包有固定 I/O 截止；取消后确认
  OVERLAPPED 完成才释放内存。短同步呈现回调与停止共用流租约锁；不能在回调里
  阻塞或重入控制器。计数区分替换、未呈现丢弃、过期、首次/重复及中性回调。
- 首次 3 项实际子进程检查为 **1 通过 / 2 失败**。新接收器曾把递增的宿主代次与每个
  新子进程从头建立的 Session 代次当成同一值，导致第二轮预览拒绝。现通过已校验的
  单次端点绑定宿主代次，同时保留并严格核对独立 worker 代次；三轮重启断言未削弱。
- 后续清理保留原协议错误，避免关闭流后把已有故障覆盖成正常停止。

I/O 使用依据：[CreateFileW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew)
与 [GetOverlappedResult](https://learn.microsoft.com/en-us/windows/win32/api/ioapiset/nf-ioapiset-getoverlappedresult)。
取消是请求，不能提前释放仍供内核使用的 OVERLAPPED/缓冲区；不声称异常内核下硬实时。

## 本机结果

Windows 11 Pro 10.0.26200、MSVC 19.29、Rust 1.99.1，D 盘独立构建与证据目录
`artifacts/2026-11-07/eye-preview-001/`。没有安装工具或依赖，Cargo 锁定离线构建。

- 新增 7 项原生检查通过：3 项真实受监督合成子进程，4 项专用本地管道故障组。
  覆盖三次启停、真实校正后 NV12/原时间、端点只取一次、队列替换、250 ms 过期、
  停止与呈现交错、断开消费者、错误身份/握手、错代次、重复帧、超长/截断包及取消。
- 既有 7 项流式、9 项离线、2 项默认状态契约通过；与新增项合计本机选定 25 项。
  没有重复此前无新条件的启动 error 5 夹具，不把选定结果写成全量本机通过。
- 构建中初始 cmd 代码页错误将构建输出放入 D 盘误编码目录；确认准确路径后移动
  **本轮生成的构建目录**到证据目录，并改用 ASCII junction。旧日志和空父目录保留，
  未删除任何用户资料。测试模块首次缺少 Windows session API feature 的编译失败也
  保留；按实际 windows-sys 0.59 绑定补齐仅测试配置，没有新增包版本。

最终源码与 CI 结果在终态后补记。已有流式 fixture 来自 `8484384` 本机保留构建，
未更改其文件；SDK 真正适配 worker 没有执行。

## 仍未通过的交付门槛

本轮完成的是可复用原生接收 API，**没有可见主窗预览或安装版成果**。当前单客户端
端点由预览消费后，不能同时直接交给虚拟设备；必须继续实现有明确输出开关的原生
转发/所有权，再接主窗。不能用本轮回调计数报告显示 FPS 或会议接收。

真实 SDK 流须先满足对应 EXE 的隔离条件；摄像头、真实自然度、虚拟设备、飞书、
音画同步和长时测试仍分层待测。正常防护下基础安装、发布者信任与商业分发许可
没有解除。保留完整数字人冻结及测试版定位，未交付稳定版。
