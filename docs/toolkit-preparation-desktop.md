# 桌面岗位准备回导

更新于2026-11-08。P2/P3已有独立岗位准备与跨块整合回导，现接入版本历史桌面入口；可移植工具仍为0.6候选。安装版、真实模型/宿主推理和长会议仍未验收。

## 使用路径

资料与模型 → 资料库 → 岗位准备：

1. **导出整理资料**：导出已经过背景整理、当前有效且未被排除的来源，以及当前本人修订。普通文件索引尚未整理的内容不包含在此范围；原文件不变，不发送网络请求。
2. 外部四角色工具用 `--scope` 规划与处理，在同一版本上完成离线评审。详细命令见[共享工具入口](../interview/toolkit/references/preparation.md)。
3. **导入准备候选**：选择 `tingxian-preparation-v1` 或含整合的v2 JSON，核对岗位匹配、参考资料、缺口和项目故事。展开依据可看文件名、定位、原文和单独的本人修订。v2还可查看冲突、原故事及省略/缺口处理。
4. **保存岗位准备**：保存独立本机视图；不会写入原文、事实卡、FTS、实时模型输入或设置。**查看已保存**会重新核对来源，旧候选标示待更新。

5. **版本历史**：按保存顺序查看，每页最多20个归档摘要；兼容旧单版本记录。点“查看”后预览原候选、依据与冲突，主列表不载入全部候选正文。
6. **恢复为当前准备**：仅来源仍有效时可用。重新核对索引版本和当前准备摘要，成功后追加版本，不覆盖历史。期间被其他操作修改时拒绝恢复，保留当前预览。
7. **导出此版本**：选择本地文件夹后导出候选JSON；失效来源的版本仍可查阅和导出，但不可恢复。取消文件夹选择不显示成功。

“保存”表示保留本次准备，不代表个人经历经核实或模型质量通过。跨块重复/矛盾已有[可选离线整合入口](toolkit-consolidation.md)，仍需Lead及三名reviewer核对语义。

## 来源与兼容

复用现有settings/background_library，未建新数据库或采集服务。首次导出分配本机库标识；不同库即便文件相同也不能直接互导候选。导入重核完整有效来源集合、原文哈希、提取版本、记录位置与当前本人修订，不能用外部工具自填的user_asserted制造用户确认。原背景v1/v2导入入口不变。

跨语言摘要明确使用递归键排序；与原生Doc序列化提取hash分别核对，不能混用。旧原文、提取注解、本人修订分别保存。导入至保存之间采用资料版本及已保存准备视图双重比较；任一变化拒绝覆盖。过期、排除、原文/提取/修订变化会使旧候选失效。

八个岗位准备原生命令仅主窗口可用；会话采集或生命周期锁被占用时不能进行导出/导入/保存/读取/历史/预览/恢复/版本导出。恢复还需等待背景整理完成。文件入口拒绝符号链接和超过16MiB的结果，导出使用新文件名且不覆盖已有文件。前端保留错误草稿，丢弃旧请求回包，长依据分批展开、故事分页。有未保存导入候选时禁用历史切换，取消导入后才能查看其他版本。页面挂载不读取历史，点按钮才请求。版本数据复用background_library，不新增资料库、实时检索或模型调用。1000版/256 MiB上限仍保持，达到上限拒绝本次写入并保留旧版本，不自动删除。
